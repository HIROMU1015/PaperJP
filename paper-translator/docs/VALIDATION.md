## 実論文の内訳

対象: [A Critique on `Quantum No-Deleting Principle', quant-ph/0005006v1](https://arxiv.org/abs/quant-ph/0005006v1)。
TeX gzip原本と同じ版の3ページPDF、abstractページ、ハッシュを保存。
`workspace/quant-ph_0005006v1/manifest.json`を参照。

- 構造: タイトル1、著者情報1、本文/要旨/連絡先13、参考文献4、計19ブロック。
- 分割: 英語2ファイルと対応する日本語2ファイル。
- 正規化文字数比: 99.6117%。独立した原文語句の網羅率: 99.8532%。
- 公開PDFから独立に抽出した語句の網羅率: 98.7591%。未解決の検証エラーなし。
- Codexが本文を翻訳し、`codex-responses/`へ保護トークン付き応答を保存。
- Claude Codeの実行は既存claude.ai認証を使用。Codexによる模擬レビューではない。
- 初回: 18 PASS / 1 NEEDS_REVISION（日付表記）。修正後に当該段落と前後段落を再レビュー。
- 標準プレビューでインライン式の空白/改行に起因する区切り崩れを発見し、
  表示用だけを空白正規化。raw_texを保持し、原文/訳が変わった2段落と文脈3段落を再レビュー。
- 現行19ブロックの有効なPASSを確認して`paper_ja.md`を生成。

この実論文には独立した図・表・ディスプレイ数式・付録・脚注がない。
それらが実論文でも検証できたとは主張せず、次のオリジナルデータで検証した。
原文の科学的結論の正しさの検証は対象外。原文の主張を勝手に訂正しない。

## 図表付きデータの内訳

`tests/fixtures/tiny/`から作成したオリジナルの小論文。
`scripts/create_preview_demo.py`、`scripts/translate_preview_fixture.py`で再現できる。
翻訳内容はCodexが作成した固定例であり、これらのスクリプトを一般的な翻訳エンジンとは扱わない。

- 複数TeXファイルのinput、節/小節、inline式、display式内の英語`\text{...}`。
- 図1とキャプション、表1とキャプション、引用と数式/図への参照、脚注、付録、参考文献。
- Codex翻訳後、Claude Codeで実レビューを実行。表内用語の指摘を修正して再レビュー。
- 標準プレビューで脚注構文の表示不良を発見し、HTML上付きリンク/アンカーへ変更。
  変更した原文・訳と周辺を再レビューし、20ブロックの現行PASS後に正式統合。
- JUnit内の模擬訳/模擬レビューはファイル契約とゲートの検証専用で、
  この実レビューや実論文レビューとは別物。

画面証拠:
[図・表・脚注の標準プレビュー](../reports/vscode-standard-fixture.jpg)、
[実論文の数式の標準プレビュー](../reports/vscode-standard-paper-math.jpg)。
前者は本文が正式版と同一の診断用ドラフトを表示した画面。非表示のドラフトコメント以外の本文は同じ。
Markdown Preview Enhancedの画面を標準プレビューの証拠として流用していない。

## 検証した拒否動作

欠落/重複/並び替え、式・引用・画像の改変、保護トークンの欠落/重複/改変、
未翻訳・空の訳、数値追加、95%境界、原本改変、画像改変、版ずれリダイレクト、
アーカイブのパストラバーサルとリンク、取得全失敗の再試行、
NEEDS_REVISION/INCONCLUSIVE、原文/訳/用語集/文脈変更による承認失効を検証。
95%以上でも独立検査に失敗すれば合格しない。
